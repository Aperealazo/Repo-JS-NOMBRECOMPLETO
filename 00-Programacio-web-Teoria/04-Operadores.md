# Operadores

Los operadores permiten realizar operaciones con valores y variables.

---

## Operadores Aritméticos

Se utilizan para realizar cálculos.

| Operador | Acción |
|----------|--------|
| + | Sumar |
| - | Restar |
| * | Multiplicar |
| / | Dividir |
| % | Resto |

```javascript
10 + 5
10 % 3
```

---

## Incremento y Decremento

Permiten aumentar o disminuir una variable en 1.

| Operador | Acción |
|----------|--------|
| ++ | Incrementa en 1 |
| -- | Decrementa en 1 |

```javascript
let contador = 0;

contador++;
contador--;
```

---

## Operadores de Asignación

Permiten modificar el valor de una variable.

| Operador | Acción |
|----------|--------|
| = | Asignar |
| += | Sumar y asignar |
| -= | Restar y asignar |
| *= | Multiplicar y asignar |
| /= | Dividir y asignar |

```javascript
let puntos = 10;

puntos += 5;
```

---

## Operadores de Comparación

Comparan dos valores y devuelven `true` o `false`.

| Operador | Acción |
|----------|--------|
| > | Mayor que |
| < | Menor que |
| >= | Mayor o igual |
| <= | Menor o igual |
| === | Igual |
| !== | Distinto |

```javascript
10 > 5
10 === 10
```

---

## Operadores Lógicos

Permiten combinar condiciones.

| Operador | Acción |
|----------|--------|
| && | Y |
| \|\| | O |
| ! | No |

```javascript
true && true
!false
```

---

## Lo que debo recordar

- Los operadores realizan operaciones.
- Los aritméticos trabajan con números.
- Los de comparación devuelven `true` o `false`.
- Los lógicos permiten combinar condiciones.
